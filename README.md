## Credit Decision Console

The working loan-review console is in [credit-console](credit-console/README.md).

Double-click **Start-Credit-Console.cmd**, then open **http://127.0.0.1:8765**.

Includes PDF/text evidence review, executable DMN rules, official EBA/Bank of Italy rulebooks, ISTAT market-comparison charts, an audit/replay view and an activity console. See [the quick guide](credit-console/delivery/START_HERE.md) and [verification report](credit-console/delivery/VERIFICATION_REPORT.json).
