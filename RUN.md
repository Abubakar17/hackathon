# Running Credit DMN Ruling Engine

Three simple commands to run the demo locally:

```bash
cd hackathon
python3 check_set.py     # Verify 10-case check set (prints 10/10 passed)
python3 app.py           # Launch web console on http://localhost:5000
```

Open `http://localhost:5000` in your browser.
Click **Preset 1 (Prime Pass)**, **Preset 2 (Denial)**, or **Preset 3 (Abstain)**, or click **Run 10-Case Check Set** for the automated verification audit.
